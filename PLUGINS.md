# Available Plugins

This document lists all available Claude Code plugins in this marketplace.

- [Api Contracts](#api-contracts-plugin)
- [Architecture](#architecture-plugin)
- [Code Intelligence](#code-intelligence-plugin)
- [Docs And Diagrams](#docs-and-diagrams-plugin)
- [Myspec](#myspec-plugin)
- [Refactoring](#refactoring-plugin)

### Api Contracts Plugin

Catch breaking API changes while drafting them: the brake MCP server and skills for OpenAPI, protobuf and GraphQL.

See [plugins/api-contracts/README.md](plugins/api-contracts/README.md) for detailed documentation.

### Architecture Plugin

Design and enforce architecture: the forge modelling MCP server and skills, plus tropism's dependency-rule skills.

See [plugins/architecture/README.md](plugins/architecture/README.md) for detailed documentation.

### Code Intelligence Plugin

Semantic code intelligence for Claude Code. Launches the symgraph MCP server on-demand via bx — no manual install required.

See [plugins/code-intelligence/README.md](plugins/code-intelligence/README.md) for detailed documentation.

### Docs And Diagrams Plugin

Author documentation that renders with Graham's text-to-document tools, starting with the adoc AsciiDoc processor.

See [plugins/docs-and-diagrams/README.md](plugins/docs-and-diagrams/README.md) for detailed documentation.

### Myspec Plugin

Repository events pushed into your running session: commits, branch changes, refused gates, approvals and archives. Adds the myspec MCP server, which doubles as a Claude Code channel.

See [plugins/myspec/README.md](plugins/myspec/README.md) for detailed documentation.

### Refactoring Plugin

Mechanical, repo-wide code changes with colab's AST-aware codemods: write the script, check the blast radius, apply safely.

See [plugins/refactoring/README.md](plugins/refactoring/README.md) for detailed documentation.
